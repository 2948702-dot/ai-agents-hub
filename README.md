# AI Agents Hub — Антигравити

Репозиторий для создания, хранения и деплоя ИИ агентов.  
Архитектура: **Claude как мозг-оркестратор**, ChatGPT / Base44 / Antigravity — специализированные инструменты.

### Принцип работы

1. **Claude** получает задачу и декомпозирует её на подзадачи
2. Если нужна альтернативная генерация / сравнение — вызывает **ChatGPT** через OpenAI API
3. Если нужен веб-интерфейс или no-code приложение — деплоит через **Base44**
4. Бизнес-специфичная логика и данные — через **Antigravity** модули
5. Claude собирает результаты и возвращает финальный ответ

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/YOUR_USERNAME/ai-agents-hub.git
cd ai-agents-hub
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить переменные окружения

```bash
cp .env.example .env
# Заполнить ключи API в .env
```

### 4. Запустить агента

```bash
python orchestration/orchestrator.py --task "Исследуй рынок электромобилей в России"
```
