# Research Agent

Исследует любую тему: собирает факты, тренды и инсайты.  
Использует Claude как основной источник и ChatGPT для верификации.

## Запуск

```bash
python agents/research_agent/agent.py "Рынок ИИ агентов в 2025 году"
```

## Пример вывода

```
Задача: Исследуй тему ...
🔧 Вызов инструмента: query_chatgpt
   Результат: ...

✅ Финальный ответ:
## Обзор
...
## Ключевые факты
...
```
